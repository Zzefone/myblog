## Human-Computer Interface

Course notes, interaction concepts, prototypes, and evaluations.

**Practical labs:** The ML-Agents lab adds trained reaching and chasing policies, training curves, and 400 recorded comparison trials. The mobile adaptation adds touch controls and a signed Android APK with eight static checks passed. Android device acceptance is deferred.

**Progress:** Homework 1 covers Lectures 1-3, with illustrated interface cases and redesigns. Lab 1 documents the blog setup and the existing Unity environment. Homework 2 covers Lectures 4-6. Homework 3 includes three AR concepts, a browser prototype, and feedback from three people. Homework 4 covers Lectures 10-12. The talking-character lab has a working Unity client using the DeepSeek API, six automated API timing records, and three rated turns from participant use with the typing indicator enabled. Multiple participants shared one code, so the exact participant count is unknown and an A/B user comparison is still pending.
